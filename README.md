
# Anti-Sleep Alarm

A simple driver safety prototype built using Arduino Nano and an IR sensor. The system monitors the driver's eye condition and activates a buzzer when the eyes remain closed for a set duration.

## Project Overview

Driving at night can make drivers feel sleepy, which may lead to dangerous situations. This project is designed to provide an alert when the driver's eyes remain closed for approximately 3–5 seconds.

## Hardware Components

- Arduino Nano
- IR Sensor
- Buzzer
- Connecting wires
- Power supply

## Working Principle

1. The IR sensor monitors the driver's eye condition.
2. The Arduino Nano reads the sensor signal.
3. If the eyes remain closed continuously for the configured 3–5 second period, the system activates the buzzer.
4. The buzzer alerts the driver.

## Main Features

- IR-based eye monitoring
- Adjustable detection time
- Automatic buzzer alert
- Compact Arduino Nano-based setup
- Designed for night-time driving safety

## Hardware Platform

**Microcontroller:** Arduino Nano

**Sensor:** IR Sensor

**Alert Unit:** Buzzer
